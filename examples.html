The cost fixture models a small loss after supplied costs. The call-data fixture interprets an illustrative maximum ERC-20 approval. A 402 challenge is payment information, not a charge.

Use real input for a paid report

Choose an input template: BSC receipt, Base USDC receipt or allowances. Replace every placeholder and declare the actual eligible customer's country. Preparation saves an exact request and private retrieval key; an approved compatible buyer separately authorizes payment. Never submit a wallet private key or seed phrase.

The walkthrough covers authorization, explicit submission, recovery and response interpretation. Preserve one original body, key and authorization across retries. Creating a new payment to fix a timeout can charge twice.

Know the boundaries

Paid services are for actual eligible customers outside mainland China, where lawful. Public docs and deterministic free tools are accessible. Network reachability does not establish customer eligibility. All reports are read-only evidence or calculations. Base L2 depth is not L1 finality; ABI decoding is not simulation; allowances are not a safety audit.
